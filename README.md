A simple configuration manager that reads and controls a file, provides methods to access key-values programmatically.

## Installation

This module is not uploaded to PyPI. I uploaded it to my server. Here is the simple command you have to run in your terminal to install the latest version:

```shell
pip install redu-config-manager --extra-index-url https://pypi.sarabserver.xyz/simple
```

Alternatively, you can build the module locally using this command after cloning:

```shell
pip install -e .
```
